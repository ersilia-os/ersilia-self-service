# 🤖 Ersilia Self Service (archived)

Ersilia Self Service let anyone request predictions from models in the [Ersilia Model Hub](https://www.ersilia.io/model-hub) by opening a GitHub issue. A GitHub Actions workflow fetched the requested model, ran it on the submitted molecules and shared the results as a GitHub artifact. A [Streamlit app](https://streamlit.io) offered the same service through a simple web form.

To learn more about how this worked, read GitHub's [blog post](https://github.blog/open-source/social-impact/automating-open-source-how-ersilia-distributes-ai-models-to-advance-global-health-equity/) about the project.

## 🚀 Where to run Ersilia models now

- **In your browser:** [hub.ersilia.io](https://hub.ersilia.io)
- **On your own computer:** install the [Ersilia CLI](https://github.com/ersilia-os/ersilia)
- **Browse the models:** [Ersilia Model Hub](https://www.ersilia.io/model-hub)
